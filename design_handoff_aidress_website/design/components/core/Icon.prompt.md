Line icon from the bundled Lucide subset; use for every glyph in UI (search, arrows, protocol/tool icons) — never emoji or unicode.
```jsx
<Icon name="arrow-right" size={16} />
<Icon name="shield-check" size={20} strokeWidth={1.5} color="var(--vermilion-500)" />
```
Default stroke 1.5. Colour inherits currentColor. Names: see ICON_NAMES / assets/icons.
