Rectangular 4px-radius button; ink primary for main CTAs, ink-outline secondary beside it.
```jsx
<Button size="lg" iconRight="arrow-right">Explore the Atlas</Button>
<Button size="lg" variant="secondary">Register Agent</Button>
<Button variant="accent">Connect</Button>
```
Accent (vermilion) is reserved for actions that resolve something — connect, verify, route. Never two accent buttons on one screen.
